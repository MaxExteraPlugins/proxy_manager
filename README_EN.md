## 📖 Description

**Proxy Manager** plugin for **exteraGram** and **AyuGram** clients.

Search and check working MTProto, WebProxy, and SOCKS5 proxies from Telegram channels.

---

## 📥 Installation

1. Navigate to the [**Releases**](https://github.com/MaxExteraPlugins/proxy_manager/releases/latest) section.
2. Download the `proxy_manager_v1.0.13.plugin` file.
3. Send the file to your Telegram Saved Messages or open it via file manager in exteraGram / AyuGram.
4. Tap the file in Telegram and choose **"Install plugin"**.

---

## 📋 Compatibility

* **exteraGram:** `>= 12.10.6`
* **AyuGram:** `>= 12.10.6`
* **Plugin SDK:** `>= 1.4.3.3`
